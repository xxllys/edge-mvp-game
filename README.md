# Distributed Multi-Variant Model Placement in Edge Computing: A Game-Theoretic Framework

This repository accompanies the paper *"Distributed Multi-Variant Model Placement in Edge Computing: A Game-Theoretic Framework"*.

## Contents

- `paper.pdf` — Full version of the paper. **This version includes the online appendix, which contains all proofs** (optimal resource allocation, NP-hardness, potential game, Price of Anarchy bounds, etc.) omitted from the conference version due to space limits.
- `figures/` — Experimental result figures:
  - `convergence` — Convergence behavior of the EMVP algorithm.
  - `social_cost_vs_num_asps` — Social cost versus the number of ASPs.
  - `storage_capacity_impact` — Impact of edge storage capacity.
  - `price_of_anarchy` — Empirical Price of Anarchy.
